# Kurama AI

Your personal AI assistant. Smart, powerful, loyal, always with you.

## Goal
A mobile-friendly AI assistant with voice, memory, study and coding help, and phone controls, later packaged as an Android app.

## Roadmap
1. Kurama interface (done)
2. Connect the AI brain (Cloudflare Worker + Gemini API)
3. Voice (speech recognition + text-to-speech)
4. Wake word
5. Memory
6. Advanced AI abilities
7. Phone controls
8. Android app
9. Security and reliability
10. Publish

## Files
- index.html: page structure
- style.css: dark and orange theme
- script.js: chat and button logic

## Security
API keys are never stored in this repo. They live on the backend only.
